# XAUUSD-97-win-rate Trading Bot

## Overview
This repository contains the A_PYRAMID_BOT_ULTIMATE.py, a high-performance trading bot for XAUUSD with approximately 97% win rate based on backtesting.

## Features
- Hybrid strategy combining EMA crossover and RSI filter
- MetaTrader5 integration for live trading
- Risk management with configurable TP/SL
- Real-time logging and monitoring

## Requirements
- Python 3.11+
- MetaTrader5 library
- Active MT5 trading account

## Installation
1. Clone this repository
2. Install dependencies: `pip install MetaTrader5 pandas numpy`
3. Configure your MT5 credentials in the bot file
4. Ensure XAUUSD.pro is in your MT5 Market Watch

## Deployment
1. Run the bot: `python A_PYRAMID_BOT_ULTIMATE.py`
2. Monitor logs and performance
3. Adjust parameters as needed
